# Hardstyle Team Dashboard

Internal web-based operations dashboard for Hardstyle Unlimited.

## Purpose

The Hardstyle Team Dashboard is used to manage:

- Jobs and orders
- Team tasks and priorities
- Upcoming deadlines
- Fighters and fight dates
- Customer and fighter contacts
- Design work and assets
- Sponsor assets
- Team assignments
- Customer and fighter history

## Team Dashboard

The dashboard is designed to work on desktop and mobile browsers.

## Development

The project is developed using Visual Studio Code and stored in GitHub.

The production website is deployed through Vercel.

## Project Structure

- `index.html` — Main Hardstyle Team Dashboard
- `README.md` — Project documentation
